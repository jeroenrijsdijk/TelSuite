TrafficCounterSuite — telrapport.html input specification
Telrapport.html accepts ZIP archives from any of the five survey apps. The app type is detected from the app_type field in _sessie.csv. Each type follows a different loading path and requires a different set of files. All CSV files use semicolon delimiters and UTF-8 encoding. File names must start with the session ID and end with the suffix shown below.

_gps.csv (v2.2+)

Routepunt bij ≥5m verplaatsing. osm_way_id en straat zijn nieuw in v2.2 — sneller verwerken in telrapport, en input voor het afleiden van _bezocht.csv.
_bezocht.csv (v2.2+)
sessie_id;datum;osm_way_id;straat;start_tijd;eind_tijd;duur_sec;n_gps;n_tellingen 20260514_131611_lok_pkt;2026-05-14;123456;Korenmarkt;13:15:50;13:16:05;15;14;3
Eén regel per bezoek (aaneengesloten verblijf op één wegvak). Visits korter dan 5s of met minder dan 3 GPS-punten worden uitgefilterd. Een gat van >30s breekt een visit. Datum staat in elke regel — self-contained voor dagdeel-classificatie in telplanning.
Flux-berekening: n_tellingen × 60 / duur_sec = passages/min
Voor oude pocket-ZIPs zonder dit bestand: gebruik build_bezocht.py om het retroactief te genereren.
